# AI20K Build Phase — Hướng dẫn onboarding

Chương trình AI20K Build Phase giúp học viên chuyển từ giai đoạn học kiến thức nền sang giai đoạn xây dựng sản phẩm AI theo nhóm. Mỗi học viên cần hoàn thành quy trình onboarding trước khi bắt đầu sprint.

## Lộ trình onboarding

1. Đăng nhập nền tảng học tập bằng tài khoản GitHub đã đăng ký.
2. Tham gia Discord server và chọn đúng cohort.
3. Chấp nhận lời mời vào GitHub Organization của chương trình.
4. Hoàn thiện hồ sơ kỹ năng, múi giờ và vai trò mong muốn.
5. Chọn nhóm dự án, đọc problem statement và xác nhận phạm vi MVP.
6. Clone repository, chạy bộ kiểm tra ban đầu và tạo nhánh làm việc.
7. Tham gia buổi kickoff để thống nhất cách giao tiếp và Definition of Done.

## Nguyên tắc làm việc

Mỗi nhóm ưu tiên một happy path hoạt động ổn định trước khi bổ sung tính năng nâng cao. Công việc phải được chia thành issue nhỏ, có người phụ trách và tiêu chí hoàn thành rõ ràng. Thành viên không commit API key, dữ liệu nhạy cảm hoặc file `.env` lên GitHub.

Trong sprint, nhóm cập nhật tiến độ hằng ngày trên Discord, mở pull request để review và ghi lại quyết định kỹ thuật quan trọng. Khi gặp blocker kéo dài quá 30 phút, thành viên cần báo sớm cho mentor hoặc đồng đội thay vì tự xử lý quá lâu.

## Tiêu chí sẵn sàng build

Học viên được xem là sẵn sàng khi đã truy cập được nền tảng, Discord và GitHub Organization; chạy được repository trên máy; hiểu problem statement; biết phạm vi MVP và kênh báo blocker. Mục tiêu của onboarding không chỉ là cấp quyền truy cập mà còn giúp cả đội thống nhất cách làm việc.
